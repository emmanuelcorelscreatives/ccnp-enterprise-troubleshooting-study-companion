# CCNP Enterprise: evidence-first troubleshooting companion

Independent learner companion for **350-401 ENCOR** and the **300-410 ENARSI** concentration. Prepared November 25, 2026 against the preserved course context for ENCOR v1.2 and ENARSI v1.1. Verify the current official topics before booking an exam.

ENCOR is the enterprise-core exam; ENARSI is the advanced-routing concentration covered here. The full CCNP Enterprise path requires the core and a concentration. ENARSI is not the only concentration option.

Use [Decision review](DECISION-REVIEW.md) for diagnosis boundaries, [Study workflow](STUDY-WORKFLOW.md) for deliberate practice, and [Official references](OFFICIAL-REFERENCES.md) for original-publisher documentation.

This package contains original explanatory study material, not exam questions, answer keys, recalled items, vendor manuals or a certification guarantee. It is not affiliated with or endorsed by Cisco. Fixed-text review cannot demonstrate interactive configuration or troubleshooting competence.

No lab subscription or hardware purchase is required to read it. Optional observations belong only on equipment or isolated labs you are authorized to use. Do not paste changes into a production network. Software trains, device families, licenses and controller modes affect applicability; no universal command syntax or default behavior is implied.
